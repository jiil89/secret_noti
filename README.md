# 시크릿노티 (SecretNoti)

카카오톡·문자·Teams 등 메신저 알림을 **폰 안에만** 저장하고, 화면 가장자리 **엣지패널**로 보여주는 안드로이드 앱입니다.
대화방을 열지 않고 알림으로 받은 내용만 보여주기 때문에 **상대에게 읽음 표시(카톡의 숫자 1 등)가 남지 않습니다.**
인터넷 권한이 없어서 저장된 기록은 폰 밖으로 나가지 않습니다.

자세한 설계는 [SPEC.md](SPEC.md)에 있습니다.

## 설치 (테스터)

1. [Releases](https://github.com/jiil89/secret_noti/releases)에서 최신 `secretnoti-x.y.z.apk`를 폰으로 내려받습니다.
   네이버 등 일부 앱·메일은 `.apk` 전송을 막으니 이 페이지에서 직접 받으세요.
2. 설치가 막히면 Play 스토어 → Play 프로텍트 → 설정에서 "앱 검사"를 잠시 끄고 설치한 뒤 다시 켭니다.
   갤럭시는 설정 → 보안 및 개인정보 보호 → **자동 차단**도 꺼야 할 수 있습니다.
3. 앱을 열고 권한 3가지를 허용합니다: **알림 접근**, **다른 앱 위에 표시**, **배터리 최적화 제외**.
   알림 접근이 회색으로 눌리지 않으면 앱 정보 → ⋮ → **제한된 설정 허용**을 먼저 누르세요.
4. 업데이트는 새 APK를 그대로 덮어 설치하면 됩니다. 기록과 설정은 유지됩니다.

카카오톡은 설정 → 알림에서 **메시지 미리보기**가 켜져 있어야 내용이 저장됩니다.

## 기능

**알림 수집·저장**
- 카카오톡, 문자(기본 문자 앱), Teams 기본 지원. LINE·WhatsApp·Telegram·Instagram·Discord·Slack·밴드 등 메시지 알림을 보내는 앱이면 설정에서 골라 켤 수 있음
- 같은 대화방 알림은 방 번호로 묶고, 메시지 고유번호로 중복 제거
- 카톡 단톡방: 방 이름(대화 바로가기 정보에서), 보낸 사람별 이름·아바타, "단톡 · N명이 보냄"
- 상대가 **삭제한 메시지도 원문 보관** + 삭제 알림, "삭제 N" 표시(열어 보면 사라짐)
- 사진 미리보기·카톡 큰 이모티콘 저장, 미니 이모티콘 "(축하해)"는 이모지·꼬리표로 표시
- 대화방별 **저장 끄기**(광고·알림톡 등), "(광고)" 대화방 표시, 광고 자동 끄기(선택)
- 카톡 등에서 먼저 읽으면 안 읽은 수·배지 정리, 엣지패널에서 빼기(선택)

**엣지패널**
- 화면 가장자리 손잡이를 탭하거나 밀어서 열기, 위치·크기·패널 폭 조절
- 밀어서 빼기, 모두 지우기, 길게 눌러 저장 끄기
- 새 메시지 표시: 숫자 배지, 반짝임(보낸 앱 색 또는 RGB 직접 선택), 미리보기 말풍선(선택)

**앱**
- 대화방 목록(상단 고정·숨기기·기록 삭제), 저장 끈 대화방은 맨 아래에 접어 두기
- 대화방 화면은 최신 메시지부터, "카카오톡에서 열기"로 원래 앱 열기(열면 읽음 처리됨)
- 검색(내용·보낸 사람·방 이름), 키워드 강조
- 앱 잠금(지문·얼굴·화면 잠금), 엣지패널·위젯 내용 가리기
- 비밀번호로 암호화한 백업·복원(사진 포함)
- 보관 기간(7일~계속), 다크 모드, 홈 화면 위젯, 한국어·영어

## 개인정보

- `INTERNET` 권한이 없습니다. 기록은 폰 안(앱 전용 저장소)에만 있고, 클라우드 백업·기기 이전에서도 제외됩니다.
- 백업 파일은 사용자가 고른 위치에만 만들어지고 비밀번호로 암호화됩니다.
- 저장소에는 실제 대화 기록이나 서명 키가 없습니다. 테스트 샘플은 이름·방 번호를 지운 것입니다.

## 빌드

필요: JDK 21, Android SDK (platform 37, build-tools 37). `local.properties`에 `sdk.dir`을 적습니다.

```
./gradlew assembleRelease testDebugUnitTest
```

- 실사용: `app/build/outputs/apk/release/app-release.apk` (R8 최적화, 릴리스 키 서명)
- 개발용: `assembleDebug` → `com.jiil.secretnoti.dev` "시크릿노티 dev"로 따로 설치됨

릴리스 서명: `local.properties`에 `secretnoti.signing=<서명 정보 파일 경로>`를 적습니다.
그 파일에는 `storeFile`, `storePassword`, `keyAlias`, `keyPassword`가 들어 있습니다. 키와 비밀번호는 저장소에 올리지 않습니다.
**키를 잃어버리면 기존 앱 위에 업데이트를 설치할 수 없으니 따로 백업해 둡니다.**
서명 키가 다르면 Releases의 APK 위에 덮어 설치할 수 없습니다.

## 기술 스택

Kotlin · Jetpack Compose (Material 3) · Room · Coroutines/Flow · Glance(위젯) · androidx.biometric
minSdk 26 / targetSdk 37 · AGP 9.5 · Kotlin 2.4 · Gradle 9.8

```
app/src/main/java/com/jiil/secretnoti/
  capture/   알림 리스너, 파서, 사진 저장, 삭제 알림, 대상 앱
  data/      Room DB, 저장소, 백업
  overlay/   엣지 손잡이·패널·말풍선 (다른 앱 위 창)
  settings/  설정 값
  ui/        화면 (design·components·screens는 디자인 계층)
  widget/    홈 화면 위젯
```
